mycroft Helm charts

A small collection of Helm charts, published on every merge to main.

Add the repository

helm repo add mycroft https://mycroft.github.io/helm-charts/
helm repo update
helm search repo mycroft

Or pull straight from OCI

helm install my-app oci://ghcr.io/mycroft/charts/app --version <version>
